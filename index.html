Лабораторні роботи

Що входить у проєкт

Спільні стилі та скрипти лежать в одному місці, а кожна лабораторна додає лише свої сторінки.

  • 1

    ЛР №1 — Створення та публікація сайту

    Головна сторінка, інформація про автора, навігація, README та Git-історія.

    Реалізовано
  • 2

    ЛР №2 — Клієнт-серверна взаємодія

    URL, DNS, HTTP-заголовки, коди відповідей, кешування, TLS та Lighthouse.

    Після публікації
  • 3

    ЛР №3 — HTML-розмітка

    Навчальний документ від 800 слів і parser-test.html з навмисними помилками.

    Очікує варіант
  • 4

    ЛР №4 — Семантика та доступність

    Несемантична й семантична версії сторінки, ARIA, JSON-LD та аудити.

    Заплановано

Структура

Без дублювання коду

Усі сторінки підключають один файл стилів і один скрипт. Лабораторні живуть у власних папках, а звіти та матеріали перевірок — окремо.

Дізнатися про автора 
web/
├─ index.html
├─ about.html
├─ assets/
│  ├─ css/style.css
│  ├─ js/main.js
│  └─ img/
├─ labs/      # сторінки ЛР №2–№4
├─ reports/   # матеріали для PDF-звітів
└─ README.md

Готово до публікації

Сайт повністю статичний і працює на GitHub Pages без збірки.
