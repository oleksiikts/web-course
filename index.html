Тема навчального проєкту

Навчальний сайт-портфоліо лабораторних робіт з веб-програмування. Протягом семестру сайт поповнюється результатами кожної лабораторної: від першої опублікованої сторінки до семантичної, доступної та перевіреної валідаторами розмітки.

Автор: Купець Олексій, група ІПЗ-26, варіант 7.

Перелік технологій, що вивчаються

  • HTML — структура та змістова розмітка документа
  • CSS — оформлення та адаптивна верстка
  • JavaScript — базова інтерактивність
  • Git і GitHub Pages — контроль версій та публікація

Лабораторні роботи

Що входить у проєкт

Спільні стилі та скрипти лежать в одному місці, а кожна лабораторна додає лише свої сторінки.

  • 1

    ЛР №1 — Створення та публікація сайту

    Головна сторінка, інформація про автора, навігація, README та Git-історія.

    Реалізовано
  • 2

    ЛР №2 — Клієнт-серверна взаємодія

    URL, DNS, HTTP-заголовки, коди відповідей, кешування, TLS та Lighthouse. Звіт — у теці reports репозиторію.

    Реалізовано
  • 3

    ЛР №3 — Адаптивний вебдизайн

    Навчальний документ (варіант 7) і parser-test.html з навмисними помилками.

    Реалізовано
  • 4

    ЛР №4 — Семантика та доступність

    Несемантична й семантична версії сторінки, ARIA, JSON-LD та аудити.

    Реалізовано

Структура

Без дублювання коду

Усі сторінки підключають один файл стилів і один скрипт. Лабораторні живуть у власних папках, а звіти та матеріали перевірок — окремо.
