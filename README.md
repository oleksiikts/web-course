# Вебпрограмування — навчальний проєкт

Репозиторій лабораторних робіт з навчальної дисципліни «Вебпрограмування».

**Автор:** Купець Олексій, група ІПЗ-26
**Варіант:** 7
**Викладач:** доц. Богут О.М.
**Тема проєкту:** навчальний сайт-портфоліо лабораторних робіт з веб-програмування
**Адреса опублікованого сайту:** https://oleksiikts.github.io/web-course/

## Перелік лабораторних робіт

- [x] Лабораторна робота № 1 — середовище розроблення, публікація документа
- [x] Лабораторна робота № 2 — дослідження клієнт-серверної взаємодії
- [x] Лабораторна робота № 3 — розмітка структури гіпертекстового документа

## Використані технології

- HTML5 — структура та семантична розмітка
- CSS3 — змінні, Flexbox, Grid, media queries
- JavaScript (без фреймворків) — мобільне меню, вкладки
- Git, GitHub, GitHub Pages — контроль версій і публікація
- Visual Studio Code, Live Server — середовище розроблення

## Структура каталогів

```
web-course/
├── index.html          головна сторінка
├── about.html          відомості про автора
├── contacts.html       контакти
├── assets/
│   ├── css/            спільні стилі
│   ├── js/             спільні скрипти
│   └── img/            зображення, favicon
├── labs/
│   ├── lab3/           документ і parser-test (ЛР № 3)
│   └── lab4/           до/після семантичної реорганізації (ЛР № 4)
├── reports/            PDF-звіти
├── .gitignore
└── README.md
```

## Локальний запуск

Відкрити каталог у VS Code → контекстне меню `index.html` → **Open with Live Server** (адреса `http://127.0.0.1:5500/`).
