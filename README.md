# Веб-програмування — лабораторні роботи 1–4

Навчальний статичний сайт (HTML5 + CSS3 + vanilla JS), що об'єднує лабораторні роботи №1–№4 з дисципліни «Веб-програмування» в одному проєкті. Без фреймворків, бекенду та збірки.

## Структура

```
web/
├─ index.html        # головна сторінка (ЛР №1)
├─ about.html        # інформація про автора (ЛР №1)
├─ assets/
│  ├─ css/style.css  # спільні стилі та design tokens
│  ├─ js/main.js     # спільний скрипт (меню, анімації)
│  └─ img/           # favicon та зображення
├─ labs/             # сторінки ЛР №2–№4
└─ reports/          # матеріали для PDF-звітів
```

## Локальний запуск

Збірка не потрібна. Відкрийте `index.html` у браузері або запустіть простий сервер:

```bash
python -m http.server 8000
# http://localhost:8000
```
